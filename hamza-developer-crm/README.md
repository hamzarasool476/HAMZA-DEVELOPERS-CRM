# HGR Developer Business CRM

Frontend CRM for Hamza Ghulam Rasool / developer business.

## Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Use Live Server for the best experience.

## Features
- Dashboard with business counters
- Projects CRUD (add/edit/delete)
- Project budgets and progress
- Client management
- Tasks with status toggles
- Lead pipeline with status updates
- Reviews and 5-star ratings
- Public portfolio section
- Search
- Responsive sidebar/mobile menu
- LocalStorage persistence
- Demo data reset
- No backend required

## Production upgrade ideas
Connect a database/API, authentication, real payments, email notifications, file uploads and analytics.
